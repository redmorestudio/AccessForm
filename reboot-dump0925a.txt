   - Server draws colored rectangles with SkiaSharp

   - Field names displayed as labels

## Implementation Plan for Interactive Field Cleaning

### Priority 1: Add Clickable Field Detection on PDF Preview (Medium Priority)
**Goal:** Enable clicking on field boxes in the preview to select corresponding table row

**Technical Approach:**
1. **Modify server-side rendering** (`/api/pdf-page-with-field-boxes`):
   - Return field click areas as JSON alongside image
   - Include field coordinates and identifiers for client-side mapping

2. **Add client-side click detection:**
   - Add JavaScript click event handler to PDF preview image
   - Implement coordinate-to-field mapping logic
   - Account for image scaling and coordinate conversion
   - Trigger SelectField() method when preview field is clicked

3. **Implementation Details:**
   - Modify Program.cs line 2647 endpoint to return field map
   - Add JavaScript interop methods in TagModificationModal
   - Handle coordinate translation between display and PDF coordinates

### Priority 2: Implement Preview-Based Field Deletion (High Priority)
**Goal:** Allow users to delete hallucinated fields directly from preview

**Technical Approach:**
1. **Add context menu or delete overlay:**
   - Right-click context menu on field boxes
   - Or hover-based delete button overlay
   - Or keyboard shortcut (Delete key) when field is selected

2. **Immediate deletion workflow:**
   - Remove field from EditableFields list
   - Update both preview and table instantly
   - Provide undo functionality for accidental deletions

3. **Implementation Details:**
   - Extend existing DeleteField() method (line 814)
   - Add JavaScript right-click handling
   - Update preview rendering after deletion

### Priority 3: Enhanced Bidirectional Selection (Medium Priority)
**Goal:** Improve field identification and selection feedback

**Technical Approach:**
1. **Improve existing table-to-preview highlighting:**
   - Current SelectField() method already updates preview (lines 800-811)
   - Add visual "pulse" or "flash" effects for better feedback
   - Ensure selected field is visible (auto-scroll preview if needed)

2. **Enhanced visual feedback:**
   - More prominent selection indicators
   - Field information tooltips on hover
   - Animated transitions for selections

### Priority 4: Interactive Field Identification for Hallucination Cleanup (High Priority)
**Goal:** Make it easy to identify and clean up false positive fields

**Technical Approach:**
1. **Enhanced field hover states:**
   - Show field details in tooltips (name, type, confidence score)
   - Highlight corresponding table row on preview hover
   - Visual indicators for potentially problematic fields

2. **Quick identification workflow:**
   - Click field in preview → highlights table row → easy delete access
   - Batch selection for similar field types
   - "Mark as hallucination" workflow with bulk cleanup

3. **Field quality indicators:**
   - Color coding based on detection confidence
   - Visual markers for fields that need review
   - Summary of field quality in validation panel

### Priority 5: Real-time Preview Updates (Optional Enhancement)
**Goal:** Eliminate manual "Update Preview" button requirement

**Technical Approach:**
1. **Automatic update triggers:**
   - Debounced updates after field property changes
   - Immediate updates for critical changes (deletion, page changes)
   - Loading states during API calls

2. **Performance optimization:**
   - Cache rendered pages to reduce server load
   - Incremental updates for single field changes
   - Background pre-rendering of adjacent pages
