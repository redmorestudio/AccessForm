## [Unreleased]

### Added
- GitHub Actions for automated builds
- Auto-update mechanism for distributed versions
- Comprehensive error logging

## [1.0.0] - 2025-08-19

### Added
- Initial release of AccessForm
- Word to accessible PDF conversion
- PDF to accessible PDF conversion
- Automatic field detection from underscores and brackets
- Support for 33 different field types
- WCAG 2.1 AA compliance checking
- Section 508 compliance validation
- Drag-and-drop file upload
- Field review and editing interface
- Dual output (original + accessible versions)
- Local processing for data privacy
- Cross-platform support (Windows, macOS, Linux)

### Technical Features
- Built with .NET 8.0 and Blazor
- Syncfusion PDF library integration
- Browser-based UI with modern design
- No external dependencies for core functionality
- Extensible architecture for AI integration
